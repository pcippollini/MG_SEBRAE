Roteirizador de Campo V1.18

GeoJSON → seleção → matriz viária → territórios OU rota total dividida → otimização → altitude → Google Maps.

1 • Base de trabalho

Use a BASE GERAL para o fluxo normal. Para uma operação/cidade específica, carregue o ARQUIVO DA OPERAÇÃO: todos os pontos dele permanecerão no HTML único, inclusive os que não entrarem nas rotas.
Base ativa: GERAL

2 • Seleção

O filtro atua somente na seleção dos pontos que entrarão nas rotas. No HTML único da operação, todos os pontos do arquivo continuam presentes.
Elegíveis pelo filtro 0
Em “Selecionar por área”, clique e arraste o mouse para desenhar um retângulo. Todos os pontos dentro dele serão selecionados. “Remover por área” faz o inverso.
Selecionados 0 / 0

3 • APIs e modalidade

A chave fica salva somente neste navegador/PC via localStorage.
Altitude só influencia os modos Priorizar descida/subida/Tempo + relevo.

4 • Divisão em rotas

Territórios contínuos formam setores compactos. “Rota total → dividir” calcula uma sequência global e a corta em trechos contínuos. Com distribuição manual, os tamanhos informados são respeitados.

5 • Gerar

Crie os setores, clique em um ponto de cada cor para definir o início e depois clique em “OTIMIZAR SETORES”.

ROTAS INDEPENDENTES

Selecione os pontos de uma rota, escolha um agente já existente no Firebase e clique em ADICIONAR ROTA. Depois selecione outro grupo em qualquer outra área e repita.

6 • PUBLICAR ROTAS PARA OS AGENTES

Associe cada rota a qualquer agente conhecido do Firebase, esteja ONLINE ou OFFLINE. O HTML gerado terá apenas os pontos daquela rota e continuará usando STATUS_PONTOS e AGENTES_ONLINE.
Os links abaixo serão montados com esta URL. Eles só abrirão pela internet depois que os HTMLs forem copiados para a pasta ROTAS do repositório e enviados ao GitHub.

7 • HTML DE ROTAS — VÁRIOS AGENTES

Gera uma única página de rotas com vários agentes. Cada agente escolhe seu nome e vê somente sua própria rota/pontos. Não existe login de GESTÃO nesta página; o acompanhamento geral fica exclusivamente no GEST_MOBILE.
